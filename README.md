# ShortcutHub V3.0 Final

Final full-stack starter for a professional shortcut-learning platform.

## Features
- React + Vite frontend
- Express REST API
- SQLite database
- JWT authentication + bcrypt
- User profile, favorites and progress
- XP, levels, streaks and achievements UI
- Learn Mode and Quiz Mode
- Shortcut of the Day
- Recently viewed shortcuts
- Admin dashboard and shortcut CRUD
- Search, software and level filters
- Light/dark mode
- Responsive mobile/desktop UI

## Run
Requires Node.js 20+.

```bash
npm install
npm run dev
```

Frontend: http://localhost:5173
API: http://localhost:4000

Demo admin:
admin@shortcuthub.local / Admin@123

Demo user:
demo@shortcuthub.local / Demo@123

Change demo credentials and JWT_SECRET before production.
